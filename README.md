# Projet Text Mining / NLP

Les deux volets du projet sont regroupés dans des dossiers indépendants, chacun avec sa documentation et ses dépendances :

- [Presse lyonnaise — Lyon News Mining](lyon-news-mining/README.md) : collecte GDELT, analyse thématique et détection de sujets émergents.
- [Bluesky — Bluesky News Mining](bluesky-news-mining/README.md) : collecte des posts déclarés en français, stockage SQLite, nettoyage et dédoublonnage exact.
